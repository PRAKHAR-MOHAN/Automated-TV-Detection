🚀 How to Increase Accuracy

01

MixUp / CutMix Augmentation

Blend two training images with a weighted λ. Forces model to generalise beyond individual images, typically adds +0.5–1.5% acc.

alpha = 0.4 # Beta distribution param
02

Increase TTA Passes N=5

Use 5 augmented test-time passes instead of 3. Each incremental pass refines the probability estimate. Adds ~+0.2% with minimal overhead.

tta_predict_fast(model, n_tta=5)
03

Unfreeze More Layers

In Phase 2, unfreeze top-120 instead of top-80 to allow deeper domain adaptation. Use a smaller LR (5e-6) to avoid catastrophic forgetting.

UNFREEZE_LAYERS = 120, LR = 5e-6
04

Larger Image Size 299×299

Upsizing from 224→299 gives the model more spatial detail to work with. Needs more GPU memory — reduce batch to 64.

IMG_SIZE = 299, BATCH_SIZE = 64
05

Cosine Annealing Warm Restarts

Use SGDR (cosine restarts) instead of a single cosine decay. Restarts help the model escape local minima during fine-tuning.

CosineAnnealingWarmRestarts
06

Class-Balanced Batch Sampler

Force exact 1:1:1:1 class ratio per batch rather than relying on class weights. Eliminates the remaining minority-class bias.

resample_dataset(..., balance=True)
